# 反模式

| 错误做法 | 风险 | 正确做法 |
|---|---|---|
| 把 key 写进 `.mcp.json` | 随插件或 Git 泄露 | 使用用户配置器 |
| 写入 shell/PowerShell profile | 长期污染通用环境 | 启动时只注入子进程 |
| 把 key 发到聊天 | 进入会话记录 | 只在隐藏提示输入 |
| 使用 `--api-key VALUE` | 暴露在命令参数 | 配置器隐藏输入 |
| 打印全量 `env` | 泄露其他凭据 | 只输出布尔状态 |
| 宣称权限文件是密钥库 | 错误安全保证 | 明确其保护级别 |
| 多用户共享作者 key | 数据和额度混用 | 每位用户独立 key |
