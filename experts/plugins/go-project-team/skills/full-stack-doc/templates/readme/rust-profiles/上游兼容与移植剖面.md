| 层级 | 含义 | 可接受证据 |

| 不支持 | 明确拒绝或尚未实现 | stable error + roadmap |

## 语言语义映射

| 上游机制 | Rust 设计 | 原因/约束 |
|---|---|---|
| 异常 | `Result<T, Error>` | 显式错误传播 |
| null | `Option<T>` | 空值可见 |
| 注解/Attribute | derive + helper attributes | 编译期元数据 |
| 反射 | trait、注册表或代码生成 | 避免动态隐式行为 |
| 继承 | trait + composition | 明确能力边界 |
| 全局单例 | `OnceLock<Arc<_>>` 或显式 context | 生命周期和测试隔离 |
| 同步/异步 | 核心同步、适配层 async 或双 API | 由运行时边界决定 |

## 兼容测试体系

```text
上游源码/测试/fixtures
        │
        ├──► 对象与方法清单
        ├──► Golden 输出
        └──► 边界与异常语义
                 │
                 ▼
        Rust parity harness
                 │
        ┌────────┼────────┐
        ▼        ▼        ▼
     API 映射  数据互通  行为差异报告
```

| 测试类型 | 目的 | 通过条件 |
|---|---|---|
| Method parity | 公共方法覆盖 | 非排除方法有实现和测试 |
| Golden | 输出兼容 | 规范化后完全一致 |
| Cross-runtime | 数据互通 | 两端均可消费 |
| Error parity | 失败语义 | 错误类别和恢复动作对应 |
| Differential | 随机输入对比 | 差异均可解释或为缺陷 |
| Compile tests | 宏和类型约束 | 合法成功、非法失败且提示稳定 |
