# Storage Selection

> Collection date: 2026-09-11.

- **JDBC** — minimal abstraction, explicit SQL.
- **JDBI** — SQL Object / handle and lightweight transactions.
- **JPA** — entity lifecycle and ORM.
- **MyBatis** — explicit Mapper / XML.
- **MyBatis-Plus** — `BaseMapper` / Wrapper and ddd4j Query translation.
- **R2DBC** — reactive database connection.
- **Panache** — Quarkus persistence adapter.

Selection criteria: runtime, transaction model, query complexity, reactive needs, dialect, and team capability.
