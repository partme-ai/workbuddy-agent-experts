# UI 规格深度 FAQ

## Q1：三端是否必须完全一致？
信息架构一致，布局和交互按视口能力调整。

## Q2：用户没有品牌色怎么办？
给语义色建议并标注非品牌事实。

## Q3：用户指定未授权字体怎么办？
保留偏好并提示许可待核验，同时给系统字体回退。

## Q4：如何处理高密度后台？
优先扫描效率与层级，不缩小到不可读字号或不可点击尺寸。

## Q5：如何处理中文长文案？
用真实长度的脱敏中文验证换行、截断和布局增长。

## Q6：视觉风格与业务冲突怎么办？
业务可用性、安全和可访问性优先，记录取舍依据。

## Q7：怎样交接给 prompt Skill？
传页面目标、布局、状态和视觉语义；远程参数仍以实时 schema 为准。

## Q8：怎样交接给开发？
附 viewport、组件状态、token 角色、交互、无障碍和未确认项，不只给截图。
