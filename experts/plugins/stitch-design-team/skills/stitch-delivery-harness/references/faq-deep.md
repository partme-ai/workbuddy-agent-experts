# 深度 FAQ

**1. 同一项目可以有多个 run 吗？** 可以；每个 run ID 唯一，不能复用目录或覆盖批准版本。

**2. 中断后从哪里恢复？** 校验 manifest、receipt 链和全部文件哈希，从最后一个完整状态继续。

**3. 远程出现两个相似屏幕怎么办？** 不能猜；按项目、创建时间、来源提示和资源 ID 对账，仍不唯一则阻塞。

**4. 固定文案是否允许 OCR 近似匹配？** 只做 NFKC 与空白归一化，关键字仍需完整召回。

**5. 美工稿为什么不直接当页面？** 图片不可证明 DOM 可编辑、控件语义和前端可维护性。

**6. 视觉分数达到阈值但用户不满意？** 用户可驳回，状态回到美术迭代；自动阈值不是批准。

**7. 缺少 OCR 或视觉工具？** 保持当前状态，列明缺少的工具与 evidence 字段，不用肉眼结论伪造通过。

**8. 能否修改已批准规格继续跑？** 可以先创建新规格版本和新 run；旧批准及归档保持不变。

**9. 如何支持暗色和亮色？** 各主题使用独立页面规格或明确 variant，分别验收和批准。

**10. 如何处理真实客户数据？** 生成前替换为演示数据；发现真实身份、联系方式、订单或凭据立即停止并清理未归档候选物。
