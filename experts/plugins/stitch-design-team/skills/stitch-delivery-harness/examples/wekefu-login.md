# WeKefu Desktop 登录页样例

- 项目规格：`.stitch/specs/login.json`
- 内容画布：1350×768，scale 1
- 设计方向：亮色桌面工作站、微信绿配商务蓝
- 固定文案包括 WeKefu Desktop 和三条产品能力说明
- 业务断言：三条宣传语平铺，不使用独立卡片容器
- 既有 `.stitch/loops/login-v1/` 仅作为可追溯输入，不改写历史

执行完成应同时得到可编辑 HTML、Stitch 渲染、美工稿、三种比较图、receipt 链和用户批准记录。浏览器或截图外框即使大于 1350×768，也不能改变内容画布验收值。
