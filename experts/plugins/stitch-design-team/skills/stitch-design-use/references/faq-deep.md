# 根路由深度 FAQ

## Q1：项目和屏幕 ID 已知时怎么路由？
直接选择目标只读或写入 Skill，不先执行无关列表调用。

## Q2：认证失败但配置存在怎么办？
转本地 setup 检查；不展示或复制凭据。

## Q3：读取后用户要求编辑怎么办？
将新请求转 `stitch-ui-designer`，并明确编辑目标和授权范围。

## Q4：设计系统和页面生成同时出现怎么办？
先由设计系统管理器确认远端系统状态，再由设计器生成或编辑。

## Q5：本地资产和远程 Markdown 有何区别？
HTML/图片走本地上传辅助；Markdown 使用远程 `upload_design_md` 合同。

## Q6：写调用超时怎么办？
停止依赖步骤，使用只读 Skills 对账，不自动重发。

## Q7：何时可以归档？
只有 Harness 对批准绑定产物和哈希完成最终验证后。

## Q8：如何处理多平台交付？
分别记录 Mobile 390x884、Tablet 768x1024、Desktop 1280x1024 的资产与验收状态，不互相外推。
