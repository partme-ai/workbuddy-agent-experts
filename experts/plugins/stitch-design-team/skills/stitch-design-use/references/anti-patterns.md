# 根路由反模式

| 错误做法 | 正确处理 |
| --- | --- |
| 只看进程环境判断未配置 | 运行 `stitch_setup.py check` |
| 读取请求交给全能写入 Skill | 选择对应的 MCP 只读 Skill |
| 把生成回执称为交付完成 | 完整交付转 Harness 并完成验收证据 |
| 删除混入普通写流程 | 转 `stitch-delete-project` 单独预览和批准 |
| “处理本地资产”直接路由到远程上传 | 先用提取/转换 Skill 本地准备，只有明确上传才发送 |

禁止让用户把密钥粘贴到聊天、禁止把未知写结果当失败后重放、禁止把本地文件存在当远程应用或视觉验收证据。
