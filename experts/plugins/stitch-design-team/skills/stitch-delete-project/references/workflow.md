# 删除项目工作流

## 输入与预览

将纯数字项目 ID 规范化为 `projects/{project}`。先调用 `get_project` 的 `name` 参数验证目标；预览必须同时展示标题、纯 ID、完整资源名和不可撤销提示。

## 批准与调用

批准必须引用当前预览的准确目标。调用 `delete_project` 时只发送：

```json
{"name": "projects/{project}"}
```

只调用一次。不要在超时、断连、空响应或 5xx 后重放删除。

## 对账

调用 `list_projects`。目标缺失是删除证据；目标仍在是未删除证据；读取失败是未知结果。未知结果不升级为成功，也不触发第二次删除。
