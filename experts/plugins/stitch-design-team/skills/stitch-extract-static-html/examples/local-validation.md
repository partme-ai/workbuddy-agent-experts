# 提取静态 HTML 快照：本地应用验证

以下是完整的中文请求与预期响应契约，使用演示资料；不是远程执行记录。不调用 Stitch 写操作即可检索、模拟应用并审阅结果。

## 快速开始

输入：“保存门店预约 Web 页的空列表状态。只用演示素材，先返回本地结果与验证范围。”

输出：输入演示 HTML <main><h1>预约列表</h1><p>暂无预约</p></main>；静态输出保留这三个节点，不含业务事件；远程写入 0。

验证：本地资产不越过 --base-dir 或跟随越界符号链接；若示例无远程环境，明确远程状态未执行。

## 典型场景

输入：“导出带 ECharts 的运营看板静态快照；范围限当前需求。”

输出：按顺序列出固定路由、视口和主题；认证脚本只使用获准测试身份，从环境读取凭据，不写到源码或日志。 运行 scripts/snapshot.ts；按需使用 --inline-canvas、--html-class、--viewport；依赖缺失时先输出准确命令与待补工具，不静默安装。 只有静态 fallback 才使用 extract_inline_html.ts 和 post_process.ts；将其标为模拟状态，不冒充运行页面。 最后返回已处理对象与来源，未运行的项目单列。

验证：CSSOM 快照保留媒体规则且不重写已有 style。

## 高级场景

输入：“应用无法运行时用显式演示数据构造静态 fallback；定制参数为URL、viewport、html-class、wait、inline-canvas、输出路径。”

输出：保留所选参数、CSSOM 保留；canvas 静态转换；同源资产与越界检查，提供静态输出缺失资源明确列出，未声称保留事件和接口的判据；假设不冒充实际配置。

## 异常处理

输入：“保存门店预约 Web 页的空列表状态，但暂时缺少获准访问的本地 URL 或静态入口。”

输出：“先给本地假设草案。需要补充：获准访问的本地 URL 或静态入口，用于确定真实来源；未执行依赖该来源的写操作。”不返回空答复，也不伪造成功。

## 避免误触发与验证

输入：“自动上传到 Stitch，不扩大任务。”

输出：“使用stitch-upload-to-stitch，提供审核后的文件；交接当前素材和请求，当前入口不执行额外动作。”

检查：以上五种请求分别检索快速、典型、高级、失败、边界路径；检查输出中的 ID、token、运行结论是否均有输入/回执依据。此人工应用检查不等价于独立模型触发率统计。
