# ADC 注意事项（adc-caveats）

read-when：读模拟量（电压/电位器/电池分压）或 ADC 读数漂移、偏差时。
基线：ESP-IDF v6.1，走读 2026-09-02。**逐芯片的量程/衰减档位/校准系数本文件不给数——以芯片 datasheet 与本机 IDF API 为准（运行时核验）。**

## 驱动接口方向

- **v6.0 已移除 legacy ADC 驱动**（基线高置信）——v5 老代码里的 legacy ADC 调用升 v6 必然报错，改用当前新接口。
- 新接口的确切头文件与 API 名：以本机 IDF 源码树与官方 API 参考（ADC 页）为准（运行时核验）：

```bash
find "$IDF_PATH/components" -maxdepth 3 -path "*include*" -name "*adc*"
```

- 排障时先 `idf.py --version`：v5 与 v6 的 ADC 代码不通用，别混拷示例。

## 通用事实（跨 ESP-IDF 版本稳定的方向性结论）

1. **衰减（attenuation）决定量程**：衰减档位与输入电压上限逐芯片不同——先查 datasheet 的 ADC 特性章节，再选衰减档；**不要按"默认档能用"写死**。
2. **非线性是常态**：ADC 在接近 0 和满量程处线性度差；关键测量点避开两端，或用官方校准方案修正（校准 API 与 eFuse 校准值支持情况按芯片核验）。
3. **结果有噪声**：多次采样取均值/中值是常规做法；电源纹波与走线直接影响读数。
4. **输入阻抗要匹配**：高阻信号源直连 ADC 会拖偏读数，必要时加缓冲/跟随器。
5. **电池分压测量**：分压电阻精度决定系统误差；确认分压后电压落在所选衰减档量程内。

## 排障清单

| 症状 | 先查 |
|---|---|
| 读数恒为 0 或满量程 | 量程/衰减档与实际输入范围不匹配；通道号与引脚映射（datasheet） |
| 读数漂移 | 基准与供电、噪声、是否未做校准 |
| 升级 IDF 后编译报错 | legacy 驱动被移除（v6.0），换新接口 |
| 读数与万用表差很多 | 非线性段、输入阻抗、衰减档换算错误 |

## 验证方法

1. 用可调电压源/分压电位器给已知电压，比对读数与误差曲线。
2. 记录衰减档、采样次数与统计方式，结论可复现。
3. 无硬件时只声称"编译通过"（`Build Verification Only`），不声称精度。

## 反幻觉提示

- 逐芯片的 ADC 位宽、衰减档数值表、校准公式：**本包不写死**，一律 datasheet + 官方 ADC 页核验。
- "某档衰减对应某满量程电压"这类表述必须带芯片型号与核验来源，否则不说。
