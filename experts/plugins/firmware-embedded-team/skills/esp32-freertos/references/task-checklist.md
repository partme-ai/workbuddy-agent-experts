# 任务设计清单（task-checklist）

read-when：新建/评审任务，或调栈与优先级。
基线：IDF FreeRTOS（Vanilla v10.5.1 修改版），走读 2026-09-02。

## 创建任务检查单（逐项确认）

| # | 检查项 | 要点 |
|---|---|---|
| 1 | 栈单位换算 | **IDF FreeRTOS 栈参数单位是字节**（上游 FreeRTOS 是字，别搬经验）；4096=4KB |
| 2 | 栈大小来源 | 由最坏路径实测（高水位）决定，不是拍脑袋常数；先保守后收紧 |
| 3 | 优先级范围 | 0 到 `CONFIG_FREERTOS_MAX_PRIORITIES-1`；**默认 25（0–24）但可配，以本项目 sdkconfig 为准**；越大越高，idle=0 |
| 4 | 绑核决策 | 双核芯片（ESP32/S3/P4/H4）才谈 `xTaskCreatePinnedToCore()`；不绑核是默认起点（见 smp-pinning.md） |
| 5 | 任务函数形态 | 不允许返回：主体是死循环；阻塞等待事件，不要忙等空转 |
| 6 | ISR 交互 | ISR 内只调 `*FromISR` 变体（上游 FreeRTOS 通用规则）；耗时处理移交任务侧 |
| 7 | 共享数据 | 队列传副本 > 裸指针共享；必须共享时用互斥量（优先级继承）或 portMUX（见 smp-pinning.md） |
| 8 | 定时器选型 | 软件定时器回调跑在定时器服务任务上下文——回调要短，勿阻塞 |

## 同步原语选型

| 需求 | 用 | 别用 |
|---|---|---|
| 传数据/事件（有副本） | 队列 | 全局变量+轮询 |
| 保护共享资源（任务间） | 互斥量（优先级继承） | `vTaskSuspendAll`（只挂起当前核，锁不住另一个核） |
| 计数资源/事件计数 | 计数信号量 | 手工计数+禁调度 |
| 单次事件通知 | 二值信号量/任务通知 | 忙等标志位 |
| 多核临界区（极短） | portMUX 自旋锁 | 长临界区（阻塞调度器） |

## 栈/优先级排障顺序

1. 复现并记录现象（复位原因、最后日志）。
2. 换算检查：所有 `xTaskCreate*` 的栈参数按"字节"读一遍，找 4 倍偏差。
3. 查 sdkconfig 实际优先级上限与各任务优先级分布；确认没有与系统任务同高优先级的忙等任务。
4. 一次只改一个维度，改后压测验证。
5. 现场取证（backtrace/coredump）→ 移交 `esp32-debug`。

## 反幻觉提示

- 栈"推荐值"表、优先级"最佳实践"数值网上版本繁杂：给建议时说明这是**项目决策**，给出验证方法（高水位+压测），不声称是官方规定。
- `uxTaskGetStackHighWaterMark` 等 API 的准确签名以本机 IDF 头文件为准（运行时核验）。
